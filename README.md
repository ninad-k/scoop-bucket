# Scoop bucket for Sevak

[Sevak](https://github.com/ninad-k/Sevak) is a keyboard-first quick launcher.

```powershell
scoop bucket add ninad-k https://github.com/ninad-k/scoop-bucket
scoop install sevak
```

Update with `scoop update sevak`. Sevak's own update check is turned off in
Scoop installs so the two never conflict.

`bucket/sevak.json` is generated from
[`packaging/scoop/sevak.json`](https://github.com/ninad-k/Sevak/blob/main/packaging/scoop/sevak.json)
and updated by Sevak's release workflow. Please open issues and pull requests in
[ninad-k/Sevak](https://github.com/ninad-k/Sevak).
